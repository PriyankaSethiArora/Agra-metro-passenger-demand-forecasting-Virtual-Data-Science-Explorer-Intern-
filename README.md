# Agra Metro Passenger Demand Forecasting
Data Science internship project focused on Agra Metro passenger demand forecasting, including project planning, EDA, visualization, modeling, and future forecasting


## About the Project

Data Science internship project focused on designing a passenger
demand forecasting framework for Agra Metro.

### Week 1 – Project Planning
- Business problem identification

- Methodology
- Proposed system architecture
- 35-hour project plan

### Week 2 – EDA & Visualization
- EDA framework
- Data exploration techniques
- Missing data and outlier handling
- Visualization strategy
- Python libraries and tools
- Reporting framework
